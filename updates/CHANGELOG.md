# Changelog

All notable changes to JoomTheme PageRail will be documented in this file.

## [0.2.0] - 2026-06-09

### Added
- Initial public release as JoomTheme PageRail.
- Floating frontend rail for Joomla Page Break Article Index.
- Right and left rail position options.
- Hover and click interaction support.
- Discovery hint bubble for better user awareness.
- Configurable hint display modes.
- Configurable hint text and timeout.
- Pulse highlight option.
- English and Turkish language files.
- Joomla 6 compatible system plugin structure.
- GPL license headers in PHP files.

### Changed
- Renamed package from internal test name to `JoomTheme PageRail`.
- Cleaned manifest metadata for public distribution.

### Notes
- Joomla core Page Break plugin remains responsible for splitting article pages.
- JoomTheme PageRail only enhances the Article Index presentation.
